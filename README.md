# Televisorium

A Nextcloud app to keep track of your movies, TV shows and watchlist. Similar to trakt.tv.

## Features

- Add movies and TV shows to your library from The Movie Database (TMDb)
- Organize titles into Watchlist, Watching, Watched, On hold and Dropped
- Browse your library by status or media type (movies, TV shows)
- Search titles in your library
- Watch progress tracking per title with auto status updates
- Episode tracking for TV shows, grouped by season
- Mark episodes as watched, track per-episode progress and see season totals
- Import all episodes of a season from TMDb
- Personal ratings per title
- Per-user metadata language selection for TMDb
- API key is stored per user account

## Requirements

- Nextcloud 31 or newer
- A free TMDb API key (v3 auth)

## Installation

Place the app in the `apps` directory of your Nextcloud installation and enable it from the apps page.

## Usage

1. Open the TMDb settings page and enter your API key
2. Use "Add title" to search TMDb and add movies or TV shows
3. Set a status from the detail view and track your progress
